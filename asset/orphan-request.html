Secure Orphan Addition Request

For security and verification, new orphan registrations require admin approval.
Why this step? We ensure every orphan is properly verified before adding to the system. Please fill in the details below and send a request to our administrator. You will receive a response within 48 hours.
Your request will be sent via your default email client. The admin will review and then grant access to the measurement form or manually create the record. No data is stored online.
Security First – All orphan additions are verified by the mosque committee.
